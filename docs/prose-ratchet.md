# Prose ratchet (#1635 S6)

`scripts/gate-prose-ratchet.sh` runs in the CI `lint` job. It counts, in tracked `*.rs` files under `crates/`, runs of four or more CJK ideographs (`cjk`) and lines with a `"` followed by 120+ quote-free, backslash-free characters (`long_literal`), and compares each count against `scripts/gate-prose-ratchet.baseline.tsv`. The baseline may only go down; `.md` files under `crates/` are not scanned because `prompts/**/*.md` and `templates/**/*.md` are where agent-facing prose belongs. The patterns' known over- and under-counts are stated in the script header.

- **Must be green — a PR that moves prose out of Rust.** Moving a prompt paragraph from a `.rs` into a `prompts/*.md` LOWERS a cell, and the gate fails with `fell from N to M … Tighten the ratchet`. Run `./scripts/gate-prose-ratchet.sh --update-baseline` and commit the regenerated tsv in the same PR; the gate is then green and the lower number is locked in.
- **Must be red — a PR that adds prose to Rust.** A new comment or literal containing a ≥4-ideograph CJK run, or a new ≥120-character string literal, in any `.rs` under `crates/` RAISES a cell, and the gate fails with `rose from N to M … new 'cjk' prose entered Rust`. The PR must either move that text into a `prompts/` or `templates/` `.md` file (rendered via `render_named` / the template roster) or, when the text is a wire literal with no synonym, argue an enumerated raise in the script header with per-file before/after counts, 1316-style. Re-running `--update-baseline` on a red branch is not a fix.
- Regenerate after every rebase or merge of `main`: the baseline is a measurement of one tree, not a fact about the code.

Positive example (green after `--update-baseline`): a `.rs` under `crates/calm-server/src/harness/` loses the literal `"任务已经完成，请先读取报告再决定下一步"` and instead declares `const NEXT_STEP: &str = include_str!("../../prompts/recovery-briefing/next-step.md");` and calls `render_named(NEXT_STEP, &[("reason", reason)])?` — the same shape `recovery_briefing.rs` already uses. `cjk` falls by two (the full-width comma splits the literal into two runs; the unit is maximal runs, not lines), the gate reports `fell from 824 to 822`, the tsv is regenerated and committed, and the gate is green.

Negative example (red, and stays red until the text moves): a new `const HINT: &str = "Read the report before choosing the next task; the summary above is a projection and may lag behind the report by one save (about 130 chars)";` (140 characters between the quotes) in any `crates/**/*.rs` raises `long_literal` by one. Breaking the line into `\`-continued pieces under 120 characters each also satisfies the gate but is a workaround; the intended fix is a `.md` under `prompts/`.

Run `./scripts/gate-prose-ratchet.sh --selftest` to prove the gate still discriminates (an injected `.rs` probe must move each cell by exactly +1, an injected `.md` probe by 0).
