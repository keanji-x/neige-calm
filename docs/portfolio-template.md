# 可通过聊天维护的投资组合模板

在正常 Neige 界面进入 **Recipes → 投资组合模板 → Save**。随后新建 Track，
选择刚保存的模板。每个新 Track 使用自己的持仓与行情，不会继承示例或其他组合。

模板正文就是 Report 的起点。图表、表格是基础组件；三节顺序、并列排布、列宽、
间距、透明背景、标题、时间范围、表格列和数据来源均保存在 `layout` 区块里。
实现不根据 Track 名字或股票代码选择特殊页面。

可以对当前 Track 的 AI 说：

- “把交易日志放到最前面，保留另外两节。”
- “把组合走势的默认范围改成 90 天。”
- “把这只股票链接到研究 Track，并记录下次复盘事件。”
- “记录这笔已经发生的交易，以及我当时的理由。”

AI 沿用正常 Report 区块读写和版本检查更新内容。持仓数量通过已有 Market data
工具登记；行情由插件更新。交易日志记录已发生的交易，不会执行券商下单。

模板默认 CNY。若插件结算币种不同，修改图表 `unit.equals`；配置与来源币种不一致
时会显示不可用，不会把美元历史直接标成人民币。未提供当日涨跌时显示 `—`。
没有历史时显示空状态；有缺失估值时不会把剩余持仓归一化成完整组合。

研究链接与下次事件位于持仓表 `data.annotations.rows`，以 `venue` 和 `asset`
联合匹配。可添加 `name`、`track`、`nextEvent`，不能覆盖插件的价格或估值字段。
交易日志使用独立的 `data.rows`。保存新模板时从空模板开始，只保留需要复用的
配置，避免把个人记录和研究 Track ID 带入新组合。

当前 Recipe 保存仍走用户的现有编辑器；AI 修改的是当前 Report。无需额外授权
AI 写入公共模板，也不新增第二套模板数据库。`linkKey` 提供研究跳转，不生成
Markdown 引用的 backlinks。

完整字段与约束见 [布局契约](report-layout-contract.md)。可编辑的原始模板见
[portfolio.md](../fe/web/src/features/report/recipe/examples/portfolio.md)。
