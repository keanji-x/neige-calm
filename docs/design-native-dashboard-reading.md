# Native dashboard reading

## Outcome and boundaries

Restore the accepted Demo's reading hierarchy in the normal Neige page, not only
inside an expanded dialog. Keep the native report as the single persisted source
for humans and Planner. No iframe, plugin-name dispatch, finance-specific layout
conditions, new execution authority, or browser-only decision persistence.

The coordinating owner approves an additive report row layout vocabulary:
`two-wide-start` and `two-wide-end`. Existing one/two/three layouts retain their
column-count meanings. Rust admission, the frontend schema, generated discovery,
shared fixtures, and the example author must agree. These are presentation ratios,
not a way to identify business content.

Palette slot 7 adds a neutral identity color. Publishers choose it explicitly;
the renderer never infers cash, a benchmark, or any other semantic category.

The Track shell receives explicit report presentation from app composition and
keeps inventory/conversations reachable while giving dashboards the default wide
reading area. Ordinary documents keep their existing presentation. Page space is
owned by Track; report components do not reach into their ancestor DOM or styles.

Charts own a compact dataset toolbar, a date cursor that works with pointer and
keyboard, exact observation values, and readable axes. There is no permanent
visible scrubber. No dataset-label parsing to reconstruct hidden business modes.
Record cards keep finding and handling separate; queue selection places the
detail alongside the selected list on wide containers, below it on narrow ones.
An optional bounded record-dataset description carries context for the selected
scenario once, without repeating it in every card. Missing/null descriptions
are valid; finding, handling and evidence remain required per record.

The coordinating owner also approves a narrow fix in the frozen `ui/dialog`
implementation: its focus traversal must include native disclosure summaries
and exclude descendants hidden by closed disclosures. Keep the public Dialog
props unchanged. Do not add caller-specific tabindex workarounds in report
components; record the directory-scoped ownership trailer under #1769.
All app-owned right-side drawers, including sources and conversations, reserve
their space through the same explicit Track presentation prop.

## Acceptance

- At 1440x1000 the native Demo uses at least 1000px of main reading width with
  auxiliary inventory collapsed. The third row's heading is visible without
  expanding a dialog. At 1280px it is reachable without excessive blank space.
- Asset summary is narrower than its curve; chart controls do not add multiple
  explanatory rows; real zero, null gaps, units and scenario cutoffs remain true.
- Card/detail reading remains coherent and usable from 320 through 1920px;
  long labels, close controls and citations do not overflow or cover content.
- Planner, inventory and keyboard navigation remain reachable; report/chart/
  evidence state survives presentation transitions without changing docRev.
- Compare actual before/after screenshots against the accepted Demo, not only
  green structural tests. Deploy only to the isolated 4143 preview; leave 4140.
