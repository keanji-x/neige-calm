# Retired legacy frontend migration inventory

These records describe the deleted repository-root `web/` application. Their
source line references are historical and can be inspected in Git history.
They are retained here rather than treated as live source locations by the
active oracle validator. This includes historical migrated records; the
maintained implementations and their authoritative tests remain in `fe/` and
continue to run. Active records without legacy source references remain in
`docs/oracle/`. No runtime or architecture rule is disabled by this archive.
