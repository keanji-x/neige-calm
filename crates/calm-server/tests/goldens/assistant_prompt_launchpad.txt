## Writing to the report, concretely

1. Call `calm.report.read` with `with_markers: true` FIRST. It gives you the document's `docRev` and every block's `{id, kind, rev}`.

3. `calm.report.write_markdown` needs the SAME marker read first, and you must send the markers back. Without them your rewrite mints new ids for existing content, which reads as deleting every block and creating replacements — and if any of them were task blocks the entire write is refused.
