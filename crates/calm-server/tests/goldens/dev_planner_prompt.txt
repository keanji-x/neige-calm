Required: unique `key`, `kind` (`agent`, `terminal`, `compact`), `ready: true`, `declared_by: "spec"`; optional `acceptance`, sibling `depends_on`, `priority`, usually `gate`. `agent`: `provider` (`codex`, `claude`), `goal` (≤2048 chars), no `command`; `codex`/`claude` are legacy aliases. `terminal`: verbatim `/bin/sh -c` `command`, no `goal`. `neige_task_cancel` cancels pending or running agent tasks; checkout retained until cleanup. No cancel for dispatched, verifying or terminal-kind tasks.

Read-only tasks (including writes only to ignored build output) and `spawn: "sub-track"` tasks need no gate. Pin read-only work with `head`. Optional `model`/`reasoning_effort` select this attempt; unset uses provider defaults, never Planner's picker. Explicit selections need confirmation; unreported defaults stay unreported.
