Select exactly one terminal_id or task_id (exact attempt_id). Sends one action against your latest live observation; request_id dedupes writes on this connection, and a replay never writes, claims or releases again. A codex task's worker refuses input and claim (error data.refusal codex_task_worker_input). Actions, inside `action`: text (never submits), submit (the text, then Enter as a separate write), key (Enter, Escape, Tab, Backspace, Delete, Ctrl+C/D/J/U/L, Up/Down/Left/Right, Home/End, PageUp/PageDown; repeat 1..32 for arrows, Backspace and Delete), click (zero-based column/row; needs mouse mode), sequence (2..8 text/key steps in one write), replace {from, to} (from must occur exactly once on the cursor row; a refusal writes nothing). Ctrl+J sends LF, Enter CR. observation_id defaults to this connection's latest observation, readbacks included. If the screen moved since, the outcome is stale_observation: nothing written, with screen_diff, a fresh observation and next saying how to resend. allow_output_since_observation accepts status-text-only changes (Escape/Ctrl+C while output streams, Enter on a draft the previous readback showed; not with a / menu open or after a pause); allow_output_below_cursor accepts only a hint line below an unmoved cursor, for draft edits. claim=true takes control first if nobody holds it (never from a human); release=true releases after the write; control_unavailable writes nothing. observe=true adds a readback; the wait arguments are calm.terminal.observe's, with the screen just before the write as baseline. Read summary first: a digest, never a verdict. application_result is always unverified. Never retry an unknown outcome with a new request_id.
