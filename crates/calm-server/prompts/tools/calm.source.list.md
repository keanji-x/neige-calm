Planner-only: list this track's captured sources without their bodies. Takes no parameters. Returns `{ sources: [{ source_id, provenance, title, published_at, content_id?, url?, quotes: [{ id, text }], body_bytes, captured_at }] }`, oldest capture first. Use it to reuse an existing `source_id` (and its `q<n>` anchors) in `neige://source/<source_id>#<quote_id>` links instead of capturing the same text again, and to see which anchors already exist before appending quotes with `calm.source.capture { source_id, quotes }`.
