Planner-only: turn a plugin result you just read into a verifiable source of this track, or add quote anchors to one. Recent plugin calls are kept per track (~2 hours, newest per tool and args). Cite as [label](neige://source/<source_id>#<quote_id>). Shapes: (1) { call: { tool, args? }, provenance, title, published_at?, content_id?, quotes? } stores exactly that call's text; tool: plugin_<id>_<tool> or mcp__neige__plugin_<id>_<tool>; no args: its latest call; provenance: full_text (e.g. Wisburg article details), summary (someone's digest, e.g. Wisburg institutional research) or web_page. (2) { manual: { text, url? }, provenance: "manual", title, published_at?, content_id?, quotes? }: your text (e.g. a page fetched outside the kernel), not kernel-verified. (3) { source_id, quotes } appends anchors. quotes: byte-exact body substrings (first occurrence; at most 2 KiB each, 32 per source). No null keys of another shape. Returns { source_id, provenance, quotes: [{ id, text }], body_bytes, body_sha256, matched_call? }. With no recorded call, call the tool again, then capture. Sources are immutable, at most 128 or 16 MiB per track: never capture the same text twice; reuse neige_source_ls ids.
