Read the calling card's bound track state. Returns `track` (row; `closed_at` null while open), `caller_card_id`, and `cards` including worker sessions. Each card has `id`, `kind`, `role`, `sort`, `created_at`, `updated_at`, and `runtime` (`CardRuntimeView`; `null` without a runtime row). `report_startup_read_required` is true iff the track-report holds content beyond the empty skeleton: a non-empty summary, or a body whose block 0 is not only HTML comments, or any later block that is not a bare `# <h1>` the contract header declares (a pre-header body counts as empty only byte for byte). `tasks`: current executions, one per key, each `{key, status, worker_card_id, access, start}`; stored execution settings: `access`=`read_only`/`read_write`, `start`=`checkout`/`upstream`. `neige track status` prints `<key> <status>[ read_only] start=<start>`; read_only appears only for readers; start always appears, regardless of status or worker liveness. Text rendering rejects missing/invalid access or start with a shape error. `--json` checks the top-level object, passes through compact JSON with a trailing newline, and does not validate task fields. Planner/worker callable; emits no event. Kernel-managed Tracks also carry creation_identity {owner, identity, timezone}, immutable even when the display title changes.
