Planner/Worker: read one file-like view from the current MCP-bound track. Supports `index.md`, `track.json`, `report.md`, `cards/index.json`, `cards/<card_id>/.meta.json`, `cards/<card_id>/.payload.json`, `cards/<card_id>/runtime.json`, `cards/<card_id>/events.json`, `cards/<card_id>/conversation.md`, `runs/index.json`, `runs/<idempotency_key>.md`, `runs/<idempotency_key>.json`, `runs/<idempotency_key>/gates/<attempt>.log`, and `plan/<key>/gate.log`. Gate logs are planner-only: the exact run/gate path preserves historical evidence; the plan-key alias selects the current log.
