Planner/Worker: read one file-like view from the current MCP-bound track. Supports `index.md`, `track.json`, `report.md`, `cards/index.json`, `cards/<card_id>/.meta.json`, `cards/<card_id>/.payload.json`, `cards/<card_id>/runtime.json`, `cards/<card_id>/events.json`, `cards/<card_id>/conversation.md`, `runs/index.json`, `runs/<idempotency_key>.md`, `runs/<idempotency_key>.json`, and `runs/<idempotency_key>/gates/<attempt>.log`. Gate logs are planner-only. Planner only: `area/reports/<name>.md`, a path listed by `calm.track.ls` or `calm.report.find`, returns the latest Markdown body of that report in the caller's area, exactly as its own `report.md` prints. A name shared by several tracks must carry its listed `~<id>` suffix; a bare shared name is refused with the candidates. A Worker is refused `area/` (-32403). On a report path, `report.md` or `area/reports/<name>.md`, `blocks: ["b_x", …]` (`neige cat <path> --blocks b_x,b_y`) returns only those blocks in document order, each preceded by its `<!-- neige:b_x -->` marker line: exactly the `text` of `calm.report.read { select: { blocks } }` for that report. An unknown id is refused with the report's blocks listed as `<id>  <heading>` lines. `sections: ["H1 text", …]` (`neige cat <path> --sections A,B`) does the same for whole H1 sections: exactly the `text` of `select: { sections }`; an unknown section is refused with the report's H1 sections listed. `blocks` / `sections` on any other path is refused. `cat` is a view: it anchors no report write, so read with `calm.report.read` before you write.
