Planner-only: close the track bound to the calling card once its goal is met or cannot be met. `message` is required and states why; it is persisted as `agent_message` on the `track.updated` event. A closed track schedules no new task and shows `closed_at` in `calm.track.state`. Closing a closed track changes nothing and returns its `closed_at`. Only the user reopens a track. Returns `{closed_at}`. The CLI form is `neige track-close --message <text>`.
