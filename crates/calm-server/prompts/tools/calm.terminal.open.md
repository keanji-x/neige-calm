Open a visible terminal card in your track. request_id makes creation idempotent: a replay returns the same terminal and runs the wait as asked. program is a /bin/sh -c command line and leaves no shell when it exits: omit it (default shell) to run several programs through calm.terminal.input. claim=true claims control in the same call, never from another client: claim {status: claimed} or {status: unavailable, reason}. wait_for, wait_ms, settle_ms, signal_events, repaint_ms, wait_text and wait_text_absent mean what they mean in calm.terminal.observe and run after the claim. format=image only when colors or layout matter. The terminal's env carries NEIGE_CLAUDE_SETTINGS, a Claude Code settings file: a Claude started with --settings "$NEIGE_CLAUDE_SETTINGS" sends its hooks as observation signals. claude_permissions {edit, bash, deny} adds allow rules (edit globs relative to the cwd, bash command prefixes) and deny prefixes; git push, rm -rf, curl, installs and edits under .git stay ask rules unless denied. A user-set track policy is inherited by an omitted list and bounds a declared one; claude_permissions_source says which applied. Use the returned terminal_id.
