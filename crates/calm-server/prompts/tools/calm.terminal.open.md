Open a visible Terminal card in your authenticated Track. request_id is required for idempotent creation; format, claim and the wait arguments never enter the idempotency key, so a replayed request_id returns the same terminal and runs the wait as asked. program is a /bin/sh -c command line run with the terminal's env (so $NEIGE_CLAUDE_SETTINGS expands); when it exits there is no shell left: omit it (default shell) when you will run several programs, and send commands with input. Returns text and observation/control state by default, without a screenshot; format=image only when colors, selection highlighting or visual layout are needed. Use the returned terminal_id; never use exec to impersonate this tool. wait_for (elapsed|change|signal|text), wait_ms, settle_ms, signal_events, repaint_ms and wait_text have calm.terminal.observe's meaning, defaults and validation and run as the open's final observation, after the claim when claim=true: a change wait waits for a change after the open (or the claim), a text wait returns once the target screen shows (a screen already present matches, wait.text.already true; the returned capture can be later than wait.text.revision). Start Claude in one call: {"request_id":"…","program":"claude --settings \"$NEIGE_CLAUDE_SETTINGS\"","claim":true,"wait_for":"text","wait_text":["trust this folder","❯"]} returns the trust dialog or the prompt with control held. claim=true claims control in the same call and returns the observation with control_id/role owner plus claim {status: claimed}; when the claim fails the open still succeeded, the waited state is returned and claim reports {status: unavailable, reason}. An open never revokes control held by another client: the claim is applied only if nobody else controls the terminal at that moment (a human who claimed first keeps control, and a replayed open after a human takeover reports claim {status: unavailable, reason: "terminal is controlled by another client"} instead of reclaiming). With format=image an image that cannot be rendered never fails the open: the text observation is returned with image {status: unavailable, reason}; after a wait that fallback shows the waited screen but its wait block is an immediate read's. The terminal's env carries NEIGE_CLAUDE_SETTINGS, a hooks-only Claude Code settings file: start Claude with claude --settings "$NEIGE_CLAUDE_SETTINGS" (or ccode --settings ...) so its lifecycle hooks (session_start, user_prompt_submit, stop, notification, permission_request, session_end, subagent_stop) arrive as observation signals; see calm.terminal.observe wait_for=signal.
