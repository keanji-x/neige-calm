Planner-only: list the reports and addressable block index for every track in the caller's area. Takes no parameters. Create links as `[label](neige://wave/<track_id>#<block_id>)`; the `#<block_id>` fragment is optional. Block ids come from this outline or `calm.report.read`. Links resolve only within the area. If an anchored block no longer exists, the link degrades to a whole-report link instead of breaking. Returns `{ tracks: [{ id, title, closed_at, blocks: [{ id, kind, heading }] }], truncated? }`; it never returns report bodies. Read the blocks you need with `neige cat area/reports/<name>.md --blocks <id>,<id>` (names from `neige ls area/reports/`).
