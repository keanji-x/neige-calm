Planner-only: say one thing to the user from a background turn. A turn that a `track.report_edited` observation woke is a quiet sync — the front end folds everything you do and say in it into one collapsed line, so an ordinary reply there is not seen unless the user expands it. Call this tool when the sync needs the user's attention; `text` is shown verbatim as one ordinary message from you, outside the fold. Exactly three situations warrant it: (a) a conflict — an edit you have not absorbed that diverges from your work: your write was refused by `if_rev` and, re-read, the user's version disagrees with what you were about to write; or the user changed a block you had just written, after you read it, to something other than what you wrote; or the user changed the `task` block of a task that is currently running. A hit on the same block that you had already read and absorbed is NOT a conflict; (b) data you cannot parse or reconcile and a person has to look at; (c) a decision only the user can make. Do not use it to report that you synced, read the report, or found nothing to do — silence is the correct outcome of most syncs. Do not use it in turns opened by a user message or a task event; reply normally there. Bounds: `text` is trimmed, must be non-empty and at most 2000 characters. Returns `{"ok": true}`; nothing is written to the report.
