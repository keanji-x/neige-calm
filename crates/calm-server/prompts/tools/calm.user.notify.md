Planner-only: say one thing to the user from a background turn. A turn that a `track.report_edited` observation woke is a quiet sync — the front end folds everything you do and say in it into one collapsed line, so an ordinary reply there is not seen unless the user expands it. Call this tool when the sync needs the user's attention; `text` is shown verbatim as one ordinary message from you, outside the fold. Exactly three situations warrant it: (a) a conflict — an edit you have not absorbed that diverges from work still in flight: it changed the `task` block of a running or not-yet-started task, changed what you are about to write this turn, or overturns a decision recorded in the report or something the user explicitly asked for earlier; a user rewriting a finished block (including undoing what you just wrote) is their final say, not a conflict — accept it silently; when you can keep the user's latest content and still complete the original request, merge and do not call — only an edit you cannot reconcile needs their decision; (b) data you cannot parse or reconcile and a person has to look at; (c) a decision only the user can make. `text` must state the concrete impact or the decision you need from the user; if you cannot name either, do not call. Do not use it to report that you synced, read the report, or found nothing to do — silence is the correct outcome of most syncs. Do not use it in turns opened by a user message or a task event; reply normally there. Bounds: `text` is trimmed, must be non-empty and at most 2000 characters. Returns `{"ok": true}`; nothing is written to the report.
