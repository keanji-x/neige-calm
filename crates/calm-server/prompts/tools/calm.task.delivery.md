Planner-only: decide a failed Git delivery of an attempt: action "retry" or "abandon", with reason. Take expected_attempt_id (the entry's attempt_id) and expected_delivery_id (candidate.delivery.delivery_id) from calm.plan.list detail=full; both must be current. idempotency_key is your request key: the same key and arguments replay the receipt, different arguments are refused. The delivery must be the latest and failed. retry needs failure.retry_allowed and the worker's workspace; it delivers the branch tip as it is now, later commits included, and settles into another task.git_delivery_settled. abandon records that no candidate will come: a gated task still verifying fails (delivery-abandoned) and frees the track; an ungated task stays done; a finished one is unchanged. Returns { delivery_id, ordinal, action }, plus task_outcome and task_status for abandon. Refusals are -32409 starting refused: and name the way out; bad arguments are -32602. Admitted on a closed track too. Neither action is a verdict on the work.
