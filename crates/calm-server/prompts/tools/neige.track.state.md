Read the current state of the track bound to the calling card. Returns `track` (the track row; `closed_at` is null while the track is open), `caller_card_id` (the calling card), and a card list so a planner daemon can see worker sessions without a second call. Each card carries `id`, `kind`, `role`, `sort`, `created_at`, `updated_at`, plus `runtime` (typed `CardRuntimeView` or `null` when no runtime row). `report_startup_read_required` is true iff the track-report holds content beyond the empty skeleton: a non-empty summary, or a body whose block 0 is not only HTML comments, or any later block that is not a bare `# <h1>` the contract header declares (a pre-header body counts as empty only byte for byte). `tasks` lists the track's current task executions, one per key, each `{key, status, worker_card_id, access}`; `access` is the stored `read_only` or `read_write`. `neige track state` prints `<key> <status>` and appends ` read_only` only for readers, regardless of status or worker liveness. Text rendering rejects missing or invalid access with a shape error. `--json` checks the top-level object and passes it through as compact JSON with a trailing newline; it does not validate task fields. Callable by planner and worker cards alike; no event is emitted. A kernel-managed Track also carries creation_identity {owner, identity, time_zone}; the identity is immutable even if the display title changes.
