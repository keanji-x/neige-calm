Planner/Worker: list the tags of this track's own report; only the Planner changes them; served as `neige tag report.md [--add T]... [--remove T]...`. `path` must be `report.md`: the track is always the one bound to the calling card, so there is no cross-track tag write. Adds apply first, then removes. Adding a tag the report already has keeps it in place; removing an absent tag does nothing; unnamed tags are never touched. A tag is trimmed and must be non-empty, at most 64 characters, with no whitespace, control character or `,`; a report carries at most 32 tags. Tags are structured metadata beside the report, never parsed from its text. A change bumps the report's update time. Returns `{"tags": [...]}`, the current tags in insertion order.
