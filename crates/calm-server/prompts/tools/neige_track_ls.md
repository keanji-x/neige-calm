Planner/Worker: list file-like read views for the current MCP-bound track. Accepts optional `{ path }`; returns `{entries: [{name, kind, …}]}`; `/` lists `index.md`, `track.json`, `report.md`, `cards/`, and `runs/`; `cards/<card_id>` lists `.meta.json`, `.payload.json`, `runtime.json`, `events.json`, and `conversation.md`. The track is derived from the bound card identity, never from arguments. Planner only: `area/` lists `reports/`, and `area/reports/` lists the reports of every track in the caller's area, own track included, as `{reports: [{path, title, track_id, tags, updated_at}]}`, newest report update first; more than 500 is refused (narrow with `neige_report_find`). A Worker is refused `area/` (-32403).
