Read the current state of the track bound to the calling card. Returns `track` (the track row), `caller_card_id` (the calling card), and a card list so a planner daemon can see worker progress without a second call. Each card carries `id`, `kind`, `role`, `sort`, `created_at`, `updated_at`, plus `runtime` (typed `CardRuntimeView` or `null` when no runtime row). `report_startup_read_required` is true iff the track-report holds content beyond the empty skeleton: a non-empty summary, or a body whose block 0 is not only HTML comments, or any later block that is not a bare `# <h1>` the contract header declares (a pre-header body counts as empty only byte for byte). `tasks` lists the track's current task executions, one per key, each `{key, status, worker_card_id}`. Legal lifecycle targets are not listed here: a refused lifecycle write names the lifecycles the caller may write from the current state. Callable by planner and worker cards alike; no event is emitted.
