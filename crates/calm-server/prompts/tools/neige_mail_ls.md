Planner-only view of this Track's mail, newest first, up to 50 per page. Optional track_id filters the other Track and state filters unread or read (as seen by the recipient). Also served as `neige mail ls [--track-id ID] [--state unread|read] [--cursor C]`. Returns {mails: [{mail_id, direction, track_id, title, summary, hop, state, sent_at, read_at}], next_cursor}. Keep the same filters when continuing with next_cursor. Listing stamps nothing.
