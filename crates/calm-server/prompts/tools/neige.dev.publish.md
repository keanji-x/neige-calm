Planner-only: publish a development PR for an attached Git track. When neige/track-<id> is at the commit of a done attempt, push it to the checkout's upstream, replacing the branch only when it is absent or at a commit an attempt of this track made, and open, or reuse, the PR against the upstream branch. Returns {ok, op_id, pr_number, head_sha, branch, base, url}; then merge as your template says. Refusals are -32409 and nothing runs: publish-not-a-candidate (a commit after the last attempt: let a task produce it, or undo it), publish-candidate-not-done, publish-no-upstream, publish-needs-track-worktree. A publish that did not land is -32409 starting publish-failed:; exit code 22 means the branch holds a commit no attempt of this track made: ask the user; 21 means the PR head did not move to the commit. idempotency_key replays the first result, a failure included: after fixing the cause use a new key; a key used for another commit is refused. title and body are the PR's; an open PR keeps its own.
