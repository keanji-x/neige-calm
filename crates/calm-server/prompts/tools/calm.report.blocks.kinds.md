Planner-only: list the block kinds a track report can contain. Returns `{ kinds: [{ kind, schema, usage }] }` where `schema` is the JSON Schema of that kind's payload. Kinds: `prose` (markdown), `chart.candles` (inline candle chart), `chart.series` (price chart resolved from a plugin tool by `source` + asset ids, no inline data), `table` (comparison table), `app` (embedded same-origin mini-app), `task` (validated task declaration; projection lands in a later slice). Creating or moving blocks requires `if_doc_rev`; read `docRev` from `calm.report.read`.
