Declare one named Codex task in an isolated workspace: workspace=empty, or workspace=verified-candidate with input {producer, slot} naming a same-track candidate producer (a review-required producer must be accepted first, see calm.task.verdict; name a returned repair_key to consume a repaired candidate). goal and acceptance are required; no dependencies, gate or report read. name is the task's track-local identity (only surrounding whitespace is trimmed): the same name and contract replays the original task, a different contract conflicts; use a new name for new work. The receipt is a declaration, not a running worker: current shows user release, the closed-track hold, contract_status and candidate_input. Acceptance is judged from the completion report. The worker's environment is fixed for every attempt: a fresh /workspace and /tmp, a read-only host /usr, no network or web search, four base tools (calm.task.complete, calm.task.fail, calm.report.read, calm.plan.list) and only the plugin_tools you delegate; current.executor_environment states it. plugin_tools accepts the registry name plugin.<id>_<tool>, its sanitized plugin_<id>_<tool> or your mcp__calm__plugin_<id>_<tool>; an ambiguous or undelegable name is refused. Grants are frozen with the task, so a task missing a capability must be re-planned, not recovered.
