Planner-only: turn a plugin result you just read into a stable, verifiable source of this track, or add quote anchors to one. The kernel records every plugin tool call you make (per track, ~2 hours, newest call per tool+args wins); a `call` capture stores exactly the text the kernel returned for that call, so a reader can later open the original and see your quotes highlighted. Cite a source in report prose as `[label](neige://source/<source_id>#<quote_id>)` (the `#q<n>` anchor is optional). Three mutually exclusive shapes. (1) `{ call: { tool, args? }, provenance, title, published_at?, content_id?, quotes? }` — `call.tool` is the plugin tool name exactly as you called it (registry spelling `plugin.<id>_<tool>` or the sanitized spelling you see); `call.args` are the arguments you passed (omit to take that tool's most recent call in this track); `provenance` states what the text IS: `full_text` (the complete original), `summary` (someone's digest of the original — the institutional research detail from Wisburg is a Wisburg-written summary, use `summary`), or `web_page`. (2) `{ manual: { text, url? }, provenance: "manual", title, published_at?, content_id?, quotes? }` — text you supply yourself (e.g. a web search result); the page marks it as not kernel-verified. (3) `{ source_id, quotes }` — append anchors to an existing source. `quotes` are byte-exact substrings of the body (copy them verbatim: same whitespace, same punctuation, no added `**` or reformatting; the first occurrence is used; ≤ 2 KiB each, ≤ 32 per source). Returns `{ source_id, provenance, quotes: [{ id, text }], body_bytes, body_sha256, matched_call?: { tool, args, completed_at } }`. Errors (-32602): the named call has no recorded result in this track (expired, evicted, never made, made by a worker, or its last run returned isError / no text / was too large — call the tool again and capture right after), an ambiguous sanitized tool name, a quote that is not an exact substring, `manual` with a non-`manual` provenance, or mixed shapes; -32403 when the track's source quota (128 sources / 16 MiB) is exhausted. Sources are immutable and never deleted; reuse ids from `calm.source.list` instead of capturing the same text twice.
