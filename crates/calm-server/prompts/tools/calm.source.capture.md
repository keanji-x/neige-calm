Planner-only: turn a plugin result you just read into a verifiable source of this track, or add quote anchors to one. The kernel keeps your recent plugin calls per track (about 2 hours, newest per tool and args). Cite as [label](neige://source/<source_id>#<quote_id>). One of three shapes: (1) { call: { tool, args? }, provenance, title, published_at?, content_id?, quotes? } stores exactly the text that call returned; tool may be spelled plugin.<id>_<tool>, plugin_<id>_<tool> or mcp__calm__plugin_<id>_<tool>; omitted args takes that tool's latest call; provenance is full_text (e.g. Wisburg article details), summary (someone's digest, e.g. Wisburg institutional research details) or web_page. (2) { manual: { text, url? }, provenance: "manual", title, published_at?, content_id?, quotes? } is text you supply, such as a web page fetched outside the kernel, marked not kernel-verified. (3) { source_id, quotes } appends anchors. quotes are byte-exact substrings of the body (first occurrence; at most 2 KiB each and 32 per source). Do not send a null key of another shape. Returns { source_id, provenance, quotes: [{ id, text }], body_bytes, body_sha256, matched_call? }. Refusals name the cause; when no call is recorded, call the tool again and capture right after. Sources are immutable, at most 128 or 16 MiB per track: never capture the same text twice, reuse ids from calm.source.list.
