Planner-only: the track's tasks. Omit key for a compact inventory; detail=full with the key gives the evidence (compare attempt_id). Omitting both returns the full plan. Entries are observations, not acceptance; a missing key has no attempt and no finished work (calm.report.read taskDiagnostics says why). status: pending and awaiting_projection wait for scheduling (blocking_reason says why); dispatched is claimed, not started; running is recorded, not proof of progress; verifying waits for the gate; done, failed and canceled are settled (status_detail says why). gate_result is the latest gate verdict (on failure status_detail is gate-red, gate-timeout or gate-infra); gate commands are not echoed. worktree and base_sha describe the attempt's workspace lease and starting commit. candidate says what the kernel committed for the attempt: binding none or unbound mints none; bound carries delivery and verification, and an advisory upstream. delivery.state: not_reported, ended_without_delivery, pending (wait for task.git_delivery_settled), committed (a candidate at ref), no_change, failed (failure.code; no candidate will come), inconsistent (accept nothing). verification: ungated, not_started, not_admitted, running, then passed, red (the only verdict that judged the code and failed it), timeout, infra (not judged), target_mismatch (the checkout differed; results discarded), unbound, not_reached, inconsistent; log_path names its gate log.
