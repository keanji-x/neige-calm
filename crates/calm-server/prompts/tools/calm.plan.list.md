Planner-only: for status start with detail=summary and the exact key when known; omit key for a compact current inventory. Use detail=full with that key for semantic evidence. Omitted arguments retain the full plan. Summaries are current observations, not acceptance or authority; compare attempt_id when reading full evidence. Gate commands are not echoed (only step names); each entry carries the latest machine gate verdict as `gate_result` (on failure `status_detail` is gate-red / gate-timeout / gate-infra). Read the worker output for a finished task via the runs views. `worktree` (only when the attempt held a workspace lease) carries the worker's lease `path` and `state`, its slice `branch`, and `last_commit` — the latest commit the KERNEL recorded for that card (a `worktree.committed` event: the auto-commit after a Codex worker's `task.complete`, or a git-forge `git.commit` action). Commits a worker makes with plain `git` are never recorded; it is never set for Claude / isolated / terminal workers unless a git-forge `git.commit` ran; and a failed auto-commit after an earlier successful kernel commit is indistinguishable from success. No event is emitted.
