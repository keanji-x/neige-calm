Worker-only: run your task's declared gate now, on your current changes. The kernel commits your checkout as this attempt's one commit above its base, with `commit_message` (the full message the repository requires: subject, body, trailers; absent, the kernel's one-line text), then runs the gate's steps on that commit in your checkout, outside your sandbox. Returns {run, commit, log_path, runs_used, runs_max, state}: `running` with the `step` in progress (call again: you join the same run, and a joining call's `commit_message` is dropped), or `finished` with `passed` and, when it did not pass, `status_detail`, `failing_step`, `exit_code` and `log_tail`. Do not edit files while a run is in progress. An attempt gets at most 5 runs. If the last run passed and you change nothing after it, that run is the gate's verdict when you report done; otherwise the kernel's gate after you report done decides.
