Planner-only compatibility interface: wholesale-replace the track's report body (and optionally `summary`). Prefer the block-addressed tools — `calm.report.blocks.upsert`/`.move`/`.delete` for targeted changes, or `calm.report.write_markdown` for full rewrites that preserve block identity via markers. Behaves like the codex `Write` file tool — clobbers prior content; block ids are re-derived best-effort. Returns `{ updated_at, docRev }`. Omitting `summary` leaves the existing summary unchanged. `message` is required and is persisted as `agent_message`; optional `lifecycle` advances the track state machine in the same atomic write.
