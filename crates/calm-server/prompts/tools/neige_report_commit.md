Planner + Assistant: commit ONE user-intent update to the track report in ONE call: ordered ops and an optional new summary (the sidebar line, about 80 characters) under one message. No revisions: every op is anchored to what this session last read with neige_report_read (a read that returned text); neige track cat anchors nothing. Default path: read the sections you change (select: { sections }), then commit section ops. { op: "replace", section, markdown } rewrites one H1 section: markdown is the whole section, starting with its # heading, with no other H1; the marker lines of your read keep block ids; a neige-block fence kept verbatim is kept, an edited one updated, a removed one deleted. Replacing a section the contract declares but the report lacks creates it in place. { op: "delete", section } removes a section. Block ops: { op: "upsert", id?, kind, markdown|payload, position? } replaces or creates a block; { op: "delete", id }; { op: "move", id, to_index }. Any refusal writes nothing: -32602 for content this session has not read or invalid input; -32001 when another writer changed what you touch since your read (re-read, merge, retry), or changed anything at all when the commit has a summary or creates or moves a block or section. Your own writes count as read. Each block and section may appear in one op. Deleting a live task block withdraws its task; a section op that would drop a live task is refused; an Assistant may not change task blocks. Returns { updated_at, docRev, blocks: [{ id, kind, rev }] }.
