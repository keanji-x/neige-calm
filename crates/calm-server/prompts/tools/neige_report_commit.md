Planner + Assistant: ONE user-intent update to the track report per call: ordered ops plus an optional new summary (sidebar line, ~80 chars) under one message. Ops anchor to this session's last neige_report_read that returned text, not to revisions; neige track cat anchors nothing. Default: read the sections you change (sections: [...]), then commit section ops. { op: "replace", section, markdown }: the whole H1 section from its # heading, no other H1; your read's marker lines keep block ids; a neige-block fence kept verbatim is kept, edited is updated, removed is deleted. Replacing a declared section the report lacks creates it in place. { op: "delete", section }. { op: "upsert", id?, kind, markdown|payload, position? } replaces or creates a block; { op: "delete", id }; { op: "move", id, to_index }. A refusal writes nothing: -32602 for unread content or invalid input; -32001 when another writer changed what you touch since your read (re-read, merge, retry), or anything if the commit has a summary or creates or moves a block or section. Your own writes count as read. One op per block or section. Deleting a live task block withdraws its task; a section op dropping a live task is refused; an Assistant may not change task blocks. Returns { updated_at, doc_rev, blocks: [{id,kind,rev}] }.
