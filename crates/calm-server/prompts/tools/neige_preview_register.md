Planner-only: expose a dev server you started for this task through calm's preview gateway so the user sees it in the report. The gateway takes a free pool port (CALM_PREVIEW_PORTS) and proxies it, websockets included, to 127.0.0.1:<target_port>; the server must listen on 127.0.0.1. Never register the calm serving this track or anything in front of it; a dev-calm you started, and an FE dev server proxying to it, are fine. key names the preview within the track; registering a key again keeps its port and repoints it, so re-register after a restart. Returns {key, port, block_hint}: block_hint is the neige_report_commit upsert payload that embeds it (you may add path and height). Viewing needs the owner logged in to calm in the same browser, over LAN http. Refusals say why. Unregister with neige_preview_unregister when the server stops for good.
