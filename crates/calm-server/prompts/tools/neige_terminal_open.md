Open a visible terminal card in your track. request_id makes creation idempotent: a replay returns the same terminal and runs the wait as asked. program is a /bin/sh -c command line and leaves no shell when it exits: omit it (default shell) to run several programs through neige_terminal_input. claim=true claims control in the same call, never from another client: claim {status: claimed} or {status: unavailable, reason}. wait_for, wait_ms, settle_ms, signal_events, repaint_ms, wait_text and wait_text_absent mean what they mean in neige_terminal_observe and run after the claim. The terminal's env carries NEIGE_CLAUDE_SETTINGS, a Claude Code settings file: a Claude started with --settings "$NEIGE_CLAUDE_SETTINGS" sends its hooks as observation signals. Use the returned terminal_id.
