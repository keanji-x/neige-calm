Planner: search the reports of every track in the caller's area; served as `neige report find .. [--name GLOB] [--tag TAG]`. `path` must resolve to the current user Area directory (normally `..`); the area is always the calling card's own, never an argument. `name` is a glob over the canonical Track name segment (without .md) (`*` any run of characters, `?` one character, everything else literal); `tag` matches one tag exactly; both given means AND, neither lists every report. Returns `{reports: [{path, title, track_id, tags, updated_at}]}`, newest report update first; `path` is a canonical /AreaName/TrackName/report.md path readable with `neige cat`, and `updated_at` is the report's own update time (RFC 3339, server offset). No match is an empty `reports`. More than 500 matches is refused, never truncated: narrow the search. Other roles are refused (-32403).
