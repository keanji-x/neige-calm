Show a live application window in the report: the reader watches it and can click and type in it. Minimal example — a commit op { "op": "upsert", "kind": "window", "payload": { "src": "/api/plugins/<id>/ws/<path>", "title": "Browser" } }. Take `src` from the plugin tool that lists its windows; do not build it by hand. While the window is closed or the plugin is stopped, the block shows it as unavailable.
