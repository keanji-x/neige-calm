Native structured read-only components, not HTML or an iframe. One version-1 composition is one atomic report block: metrics, time-series, distribution, table and records arranged in bounded one/two/three-column rows. A cell is inline or a live slot {kind:"live", id, source:"neige://plugin/<plugin_id>/<overlay_kind>", expects:<cell kind>}: a reference to one plugin data unit {snapshot, cell} that neige_report_read resolves per slot. Inline cells need the view snapshot (identity and timestamps); it is null exactly when every cell is a live slot. Labels, evidence and semantic tones belong to the publisher. Views with live slots are template-owned (Track recipe): do not author, move or rewrite their slots. No actions, scripts, URLs or tool calls. Read the canonical payload with neige_report_read; updates use neige_report_commit anchored to this session’s read. See docs/design-native-report-composition.md.
